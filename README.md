# AEGIS — Real-Time Card Fraud Decision Platform

A prototype card-issuer fraud platform exploring fraud as a multi-persona product problem.

**Live demo:** https://NidhiR797.github.io/aegis_fraud_platform_v2.index.html

## Personas
- **Fraud Analyst** — case review, SLA tracking
- **Strategy Manager** — false-positive cost, friction analysis
- **Risk Leader** — fraud rate (bps), chargebacks, decision latency
- **Customer Support** — case context, customer impact

## Status
Self-initiated prototype built with Claude. UI and interaction patterns are functional; data is illustrative.

## Why this exists
Built to explore AI-assisted decisioning in regulated, audit-sensitive payment workflows.
