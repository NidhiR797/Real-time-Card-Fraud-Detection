🛡️ Aegis

Real-time Card Fraud Detection Platform

Aegis is an end-to-end fraud detection system that analyzes card transactions in real time, flags suspicious activity, and gives investigators an interactive dashboard to explore alerts, patterns, and model decisions.

Key Features

  • Real-time transaction scoring with ML-based risk models
  • Interactive dashboard for monitoring alerts and trends
  • Explainable predictions to support investigator decisions
  • Visual analytics on transaction patterns and fraud hotspots
